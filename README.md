# Pues me presento

Comedia política ficticia, single-player, tercera persona y low poly. Primera experiencia jugable construida con Babylon.js, JavaScript ES modules y Vite.

```powershell
npm.cmd ci
npm.cmd run dev
```

Abrir http://127.0.0.1:5173. WASD: moverse; Shift: correr; ratón: cámara; E: interactuar; Escape: pausa. Clic captura el cursor; también puedes arrastrar para mirar. En diálogo, Espacio/Enter completa y después continúa; 1–3 elige respuesta.

Incluye un recorrido provisional de los seis capítulos: piso, llamada, partido, plaza, sede, vídeo, crisis, debate, mitin, elecciones deterministas, derrota con reintento y victoria. Es el milestone 2, **no la campaña completa de dos horas**.

`npm.cmd run build` genera `dist/`; `npm.cmd run preview` sirve la build en http://127.0.0.1:4173. No requiere recursos remotos. No está empaquetado aún para Electron/Steam.

Ver `CLAUDE.md` para comandos y continuidad; `docs/STATUS.md` para validación; `docs/MILESTONES.md` para alcance y siguiente hito; `docs/ART.md` para Blender/GLB/animaciones.
