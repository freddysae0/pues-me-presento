# Ramas del guion

El juego usa un solo guion: `src/data/script/actual.js` como base con la rama B (`src/data/script/b.js`, «Sátira de argumentario») fusionada encima. No hay selector de guion. `B.md` documenta esa rama.

`archive/a.js` y `archive/c.js` (y sus notas `A.md`, `C.md`) son ramas archivadas: el juego no las importa ni las prueba; se conservan solo como referencia.
